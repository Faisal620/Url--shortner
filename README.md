URl- Shortner
A basic URL shortener project built with Node.js, Express and MongoDB.

Users can create short URLs and use them to redirect to original links.
This project also includes user authentication and server-side rendering using EJS.

Features :-
* User signup and login
* Generate short URLs
* Redirect using short links
* MongoDB database integration
* JWT authentication
* EJS templates

Tech Used:-
* Node.js
* Express.js
* MongoDB
* EJS
* JWT
* Bootstrap
